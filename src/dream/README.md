# 造梦层

`materials.js` 收集明确布局的素材并比较输入指纹；`pipeline.js` 执行三阶段结构化生成；`worker.js` 只接收快照与模型 RPC，不接收 Host Context 或文件权限。运行与限制见 [开发说明](../../docs/development.md)。

负责素材收集 → light → REM → deep → 梦境落盘与汇报内容生成。

- 输入：长期/中期记忆、最近三天日记、未固化素材和会话游标。
- 输出：带来源的候选提案，以及明确标注为梦境的叙述。
- 候选分为事实、偏好、人格提案、未完成约定；梦不是事实证据。
- 不直接修改真实记忆或 AGENTS.md；由 review 审核、storage 应用。
- 原始梦境允许碎片化，面向用户的报告应区分梦中感受与事实。
