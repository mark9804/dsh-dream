# 存储与应用层

`index.js` 提供注入式记录与事务存储；`local-files.js` 仅用于合成测试和演示。生产路径使用 Harness FS 适配，不直接用 Node FS 改真实记忆。

负责 dream-state.json、梦境、提案与拒绝记录、备份及已批准的记忆变更。

- 运行时数据放在明确配置的数据目录，不写入插件源码目录。
- 写前校验版本并备份；单文件原子替换不等于多文件事务，需要提交记录与恢复策略。
- 应用成功后才推进已提交游标，失败不得假报完成。
- 去重后再处理过时记忆；淘汰先归档，真正删除必须经用户确认。
- 梦境和真实记忆分开保存；敏感内容不得进入检索索引。
- 不直接修改 Harness 会话日志或数据库；插件状态只作派生缓存与审计记录。
