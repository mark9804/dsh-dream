# 醒来与审核层

`index.js` 记录目标 agent 的可信审核回执、版本基线和改判历史；accept 部分可先提交，defer 留待后续。普通提案由 agent 自审，无需用户逐条批准。

负责事实核查、逐条 accept / reject / defer 和受保护内容检查。

- 默认不接受；未审核和 defer 的提案不得写入真实记忆。
- 事实必须指向原始证据；人格提案必须提供事件来源、diff 与影响说明。
- 红线与称呼不可由梦修改；pinned 内容不能因过时而淘汰。
- 保留拒绝记录，避免重复说服；区分审核版本，防止旧提案覆盖新记忆。
- 返回明确的审核结果，不在本层触发压缩或偷偷改文件。
