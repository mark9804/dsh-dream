# Harness 适配层

已按 `0.2.1-rc.3` 的静态 SDK 证据实现 files/model/control/tools 适配，并通过模拟边界测试；尚未完成真实 profile 验收。接口依据与限制见 [接入手册](../../docs/harness-integration.md)。

集中处理 Host 服务接入、agent 生命周期、应用后的压缩与重读提示。

- 不覆盖 `/compress`，不假定命令名就是可调用的 Service 方法。
- 当前运行时服务目录已发现 compaction；实际接入前须 Inspect 查询其精确契约及所需 agent 上下文。
- 顺序必须是审核完成 → 已接受变更提交成功 → 压缩 → 提示重读 → 汇报。
- 压缩失败与写入失败分别记录，避免重试时重复应用已提交的变更。
- 事件名、派发模式、服务签名必须现场查询，不凭猜测订阅或调用。
- 注册的定时器、监听器及跨 agent 资源必须由插件生命周期清理。
